Paul Business Solutions Website

Overview

This repository contains the source code for the official Paul Business Solutions (PBS) website.

PBS provides:

CRM Implementation

Workflow Automation

AI Automation

Business Process Consulting

Software Integration & Support

This website is intended to generate leads, build credibility, and encourage visitors to book a consultation.

HTML5

GitHub Pages (deployment)

Local Development

Open the project folder in VS Code.

Install the Live Server extension (recommended).

Right-click index.html.

Select Open with Live Server.
